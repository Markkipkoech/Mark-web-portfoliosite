CompanyHub

CompanyHub is a business management platform I am developing to address practical operational needs of Kenyan small and medium-sized businesses. The project focuses on building reliable backend systems for business operations, with attention to data integrity, authorization, maintainability and dependable business workflows.

Engineering work: Modular backend application structure; business logic organized around domain services; API development and resource access controls; database integrity and financial calculation rules; concurrency-aware sales operations; automated testing across application and database behavior.

My role: Founder and developer, responsible for product direction, engineering decisions and implementation.

Backend Engineering Learning Journey

This is my practical learning project documenting my development toward becoming an independent backend software engineer. It combines structured study, programming exercises, technical research and practical experimentation to develop the knowledge required to design, build, test and maintain reliable backend systems.

Learning areas: Python and programming fundamentals; relational databases, SQL and PostgreSQL; Django and Django REST Framework; backend architecture and software design; authentication, authorization and security; transactions, concurrency and data integrity; testing, debugging and software quality; DevOps, infrastructure and application reliability.

Engineering artifact: I have developed a Python learning-record utility that validates learning entries, generates dated Markdown records and updates a progress tracker while protecting existing records.
