CompanyHub — Database-level safeguards for sales integrity

Project context

CompanyHub is an in-development business management platform. This page does not present it as publicly available or deployed in production.

Milestone

The relevant local repository history records work on database-level safeguards for sales integrity.

What the milestone covers

  • Same-business sale-line relationships: keeps sale lines associated with records from the same business.
  • Sale completion data and totals: checks that completion data and totals are valid.
  • Lifecycle transitions: applies safeguards to changes in a sale's lifecycle.
  • Completed records: protects completed sale records from changes that would alter their history.

The local repository history includes integrity test files for both SQLite and PostgreSQL. No test execution results are claimed on this page.
